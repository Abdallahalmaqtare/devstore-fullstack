# DevStore — الإصدار الخامس (إصلاحات حرجة + بحث + Player ID في السلة)

## الإصلاحات في هذا الإصدار
1. **إصلاح "تواصل للاتفاق"**: النافذة تفتح بشكل مؤكد (معالجة الحدث موثّقة بـ data-inquire)، وتُبنى روابط واتساب/تليجرام من إعدادات الموقع مع إعادة جلبها تلقائياً لو لم تُحمّل، والنص مشفّر بـ encodeURIComponent ويحمل اسم الخدمة + التصنيف + بيانات المستخدم، والخادم يرجع أحدث الأرقام لتحديث الرابط قبل فتح المحادثة.
2. **إصلاح "البيانات خاطئة"**: دالة توحيد واحدة `cleanPhone()` في الخادم (تسجيل + دخول + أدمن) تُبقي الأرقام فقط، مع try/catch في مسار الدخول لكشف أي خطأ صامت. أُضيف خيار **"تذكرني"**: مفعّل ← localStorage + توكن 30 يوماً، غير مفعّل ← sessionStorage + توكن 12 ساعة (تُنهى الجلسة بإغلاق المتصفح).
3. **إصلاح "انتهت صلاحية الرمز"**: أُعيد تصميم تخزين OTP — بلا حقل expiresAt يدوي، بل TTL index على `createdAt` (10 دقائق) وفحص الصلاحية يقارن بنفس المرجعية، والرمز **لا يُحذف إلا بعد نجاح العملية كاملة** (إنشاء الحساب أو تغيير كلمة المرور فعلياً) — وفي مسار الاستعادة لا يُستهلك عند التحقق بل عند نجاح تغيير كلمة المرور.
4. **Player ID انتقل إلى السلة**: كرت المنتج بسيط (زر "أضف للسلة")، وحقل "🆔 معرّف الحساب / Player ID" يظهر داخل عنصر السلة نفسه للمنتجات التي تتطلبه، يُحفظ أثناء الكتابة، يُفحص عند تأكيد الطلب، ويُخزّن في `order.items[].accountId` ويظهر في لوحة الأدمن وإشعار تليجرام.
5. **بحث فوري + فئات دقيقة**: شريط بحث حي أعلى المتجر يفلتر بالاسم والوصف، والفئات: 📱 تطبيقات / 💬 أرقام وهمية / 🎮 ألعاب / 🛠️ أدوات المبرمجين / 🎓 خدمات وتدريب — ونموذج الأدمن يتيح النوع والقسم وخيار ID بمرونة كاملة.

## ⚠️ ترحيل إجباري لقاعدة البيانات
نظام الفئات تغيّر (أُضيفت `apps`) وتصميم OTP تغيّر — نفّذ في MongoDB Atlas:
1. احذف مجموعة `products` ثم شغّل `node server/src/seed.js`
2. احذف مجموعة `otps` (لإعادة بناء فهرس TTL الجديد)

## التشغيل
```bash
npm install
cp .env.example .env
node server/src/seed.js
npm run dev   # http://localhost:3000
```
