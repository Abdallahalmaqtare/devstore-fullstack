# DevStore — الإصدار الرابع (تحسينات UX + Player ID + روابط تواصل جاهزة)

## الجديد في هذا الإصدار
- **توحيد صيغة رقم الهاتف** في كل النوافذ (دخول، تسجيل، استعادة، ملف شخصي، دخول الأدمن): صيغة دولية بدون `+`، نص إرشادي واضح، ودالة `normalizePhone()` تحذف أي مسافات/شرطات/`+` قبل الإرسال — والخادم ينظّف الرقم مجدداً ضماناً للتطابق في قاعدة البيانات.
- **واجهة OTP محسّنة**: مربعات 44×50px، خط 1.25rem عريض، حواف 8px، حاوية Flexbox متوسطة بفواصل 8px، اتجاه LTR مع تنقّل تلقائي ولصق كامل للرمز.
- **حقل معرّف الحساب (Player ID)**: checkbox في نموذج الأدمن "هل يتطلب إدخال ID الحساب؟" ← يظهر حقل إلزامي في بطاقة المنتج ← يُحفظ في `order.items[].accountId` ← يظهر في جدول الطلبات باللوحة وفي إشعار تليجرام (سطر `🆔 الحساب`)، مع تحقق خادمي يرفض الطلب بدونه.
- **روابط تواصل جاهزة للخدمات الاستشارية**: زرّا واتساب وتليجرام في نافذة "تواصل للاتفاق"، برسالة واتساب مشفّرة (`encodeURIComponent`) تتضمن اسم الخدمة + التصنيف (دورة تدريبية / مشروع تخرج / تكليف جامعي) + اسم المستخدم وهاتفه (تُعبأ تلقائياً إن كان مسجلاً وتتحدث لحظياً مع الكتابة)، ورابط تليجرام مباشر لمحادثة الدعم، مع إشعار فوري لبوت الإدارة يتضمن التصنيف.

## التشغيل
```bash
npm install
cp .env.example .env    # عبّئ القيم
node server/src/seed.js # بيانات أولية (تشمل requiresAccountId وتصنيفات الخدمات)
npm run dev             # http://localhost:3000
```
لو قاعدتك فيها بيانات قديمة: احذف مجموعة `products` من MongoDB Atlas ثم أعد تشغيل `seed.js`.

## النشر على Render
- Build: `npm install` — Start: `node server/src/index.js`
- أضف متغيرات `.env.example` من Environment (لا ترفع `.env`)
- نفّذ `node server/src/seed.js` مرة واحدة من Render Shell
