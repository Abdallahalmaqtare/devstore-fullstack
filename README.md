# DevStore — الإصدار الثامن

## الجديد
1. **OTP آلي**: رابط بوت تليجرام `t.me/<BOT>?start=otp_xxx` — العميل يضغطه فيصله الكود آلياً عبر مسار `GET /api/auth/bot-code`، مع بقاء قناة واتساب الدعم كاحتياط. فعّلها بضبط `TELEGRAM_BOT_USERNAME`.
2. **العملات المتعددة**: مجموعة `currencies` في قاعدة البيانات + قسم "💱 إدارة أسعار الصرف" في إعدادات الأدمن (YER=540, SAR=3.75, EGP=50, IQD=1310...) + قائمة عملات بأعلام في شريط التنقل، والأسعار تُعرض مزدوجة: `$2 / 1080 YER`، محفوظة في localStorage.
3. **شبكة الجوال**: عمودان للكروت على الشاشات ≤768px مع مسافات وأيقونات مدمجة.
4. **الأقسام الديناميكية**: تبويب "🗂️ إدارة الأقسام" بالكامل (إضافة/تعديل/ترتيب/إخفاء) — فلاتر المتجر وقسم الخدمات تُبنى منها تلقائياً.
5. **محدد رمز الدولة**: قائمة أعلام ورموز في كل حقول الهاتف (افتراضي 🇾🇪 967)، العميل يكتب رقمه المحلي فقط ويُدمج الرمز برمجياً ويُحفظ صافياً.

## التشغيل
```bash
npm install && cp .env.example .env   # عبّئ القيم + TELEGRAM_BOT_USERNAME
node server/src/seed.js               # يدرج الأقسام والعملات (upsert آمن)
npm run dev
```
