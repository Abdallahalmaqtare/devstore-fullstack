# DevStore — الإصدار التاسع (إصلاح OTP + حذف المستخدمين + إدارة المسؤولين)

## الإصلاحات والإضافات
1. **إصلاح OTP والبوت**: كان سبب التوقف return مبكر داخل issueOtp يمنع وصول إشعار تليجرام للأدمن — أُعيدت كتابة auth.js بالكامل. الآن عند التسجيل أو الاستعادة يصل الأدمن فوراً: نوع العملية + اسم العميل + هاتفه + الكود (صالح 10 دقائق). وخيارا العميل: زر بوت تليجرام (t.me/<BOT>?start=otp_<TOKEN> يستلم الكود آلياً عبر /api/auth/bot-code) وزر واتساب برسالة جاهزة تحمل رقمه ونوع الطلب.
2. **حذف المستخدمين**: زر 🗑️ بجانب كل مستخدم مع نافذة تأكيد، ومسار محمي DELETE /api/admin/users/:id يحذف الحساب نهائياً ويلغي طلباته المعلقة.
3. **إدارة المسؤولين**: تبويب "🛡️ إدارة المسؤولين" — جدول الأدمن (اسم/هاتف/تاريخ/رتبة) + نموذج إضافة أدمن جديد (اسم/هاتف/كلمة مرور أولية مشفرة bcrypt). المسارات: GET /api/admin/admins، POST /api/admin/create-admin، DELETE /api/admin/admins/:id (سحب الصلاحية بتحويله لمستخدم). كلها مقيدة بالمدير العام (isSuper)، وحساب المدير العام محمي من الحذف والتخفيض.

## التشغيل
```bash
npm install && cp .env.example .env
node server/src/seed.js
npm run dev
```
