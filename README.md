# DevStore — الإصدار السادس (مجموعات وباقات + توجيه مباشر لمنسق الخدمة)

## الجديد في هذا الإصدار

### 1) نظام المجموعات والباقات (Category Groups & Variants)
- **نموذج البيانات**: المنتج يحمل `variants: [{ name, price, icon }]` — إن وُجدت باقات يصبح "مجموعة"، وإلا فهو سلعة مفردة بسعر مباشر.
- **واجهة المتجر**: الألعاب والتطبيقات والأدوات تُعرض كبطاقات مجموعات (PUBG، Free Fire، Roblox، TikTok، Soul، Tango، SamFw، Chimera، DFS...) بزر "📦 عرض الباقات (N)" يفتح نافذة منبثقة أنيقة بكل باقة وسعرها وزر إضافة للسلة.
- **الطلبات**: العنصر يُحفظ باسم "المجموعة — الباقة" والسعر يُحسم من قاعدة البيانات (اسم الباقة يُطابق في الخادم، منع التلاعب).
- **لوحة الأدمن**: محرر باقات ديناميكي (صفوف إضافة/حذف: اسم الباقة + السعر + أيقونة) + خانة "يتطلب Player ID" + جدول يعرض نوع العنصر (مجموعة/سلعة/خدمة) وعدد الباقات وأقل سعر.

### 2) التوجيه المباشر لمنسق الخدمة
- **حقول جديدة في نموذج الخدمة**: واتساب المنسق (دولي بدون +) ويوزر تليجرام المنسق — فارغة = قنوات الدعم العامة.
- **واجهة العميل**: نافذة "تواصل للاتفاق" تتضمن اختيار نوع الحضور (🌐 عن بُعد / 📍 حضوري في الحديدة — يُظهر فقط ما تدعمه الخدمة)، وزرّي "واتساب المنسق" و"تليجرام المنسق" يفتحان المحادثة المباشرة برسالة جاهزة مشفّرة:
  ```
  مرحباً، أود الاستفسار والتسجيل في:
  - الخدمة: دورة تدريبية — دورة برمجة لغة C++
  - نوع الحضور: حضوري في الحديدة
  - اسم العميل: ...
  - رقم الهاتف: ...
  ```
- الروابط تُبنى من قنوات المنسق المخزّنة في الخدمة، والخادم يرجع القنوات الفعلية عند الإخطار لتحديث الرابط قبل فتح المحادثة.

## ⚠️ ترحيل إجباري
احذف مجموعة `products` من MongoDB Atlas ثم شغّل `node server/src/seed.js` (البذور الآن بصيغة المجموعات والباقات).

## التشغيل
```bash
npm install
cp .env.example .env
node server/src/seed.js
npm run dev   # http://localhost:3000
```
