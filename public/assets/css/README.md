# DevStore — الإصدار العاشر (تسليم OTP الآلي عبر Telegram Deep Linking)

## آلية التسليم الآلي للكود (بلا تدخل يدوي)
1. العميل يطلب رمزاً (تسجيل/استعادة) ← الخادم يولّد OTP (6 أرقام، 10 دقائق) + `linkToken` فريداً مرتبطاً به في MongoDB.
2. الواجهة تعرض زر "✈️ استلام الكود عبر تليجرام" برابط: `https://t.me/<BOT_USERNAME>?start=otp_<TOKEN>`.
3. العميل يضغط Start في البوت ← تليجرام يرسل التحديث فوراً إلى `POST /api/telegram/webhook`.
4. الخادم يقرأ `<TOKEN>`، يطابقه مع رقم الهاتف والكود، ويرد على العميل فوراً:
   "🔐 رمز التحقق الخاص بك في DevStore هو: 123456 — صالح لمدة 10 دقائق."
5. يُحفظ `chat_id` العميل في حسابه (`telegramChatId`) لإشعارات مستقبلية مباشرة.
6. إشعار الأدمن يبقى كنسخة احتياطية (العملية + العميل + الهاتف + الكود + تأكيد التسليم الآلي).

## التفعيل (خطوتان)
1. في `.env` / Render Environment أضف:
   - `TELEGRAM_BOT_USERNAME` (يوزر البوت بدون @)
   - `PUBLIC_URL` = رابط موقعك العام، مثال: `https://devstore-xxxx.onrender.com`
2. شغّل الخادم — يُسجَّل الـ Webhook تلقائياً عند الإقلاع (سترى "✅ Telegram Webhook مسجل").

محلياً للتجربة: `npx ngrok http 3000` وضع رابط ngrok في PUBLIC_URL.

## إزالة مؤقتة للـ Webhook عند التجربة المحلية بدون ngrok
تجاهل PUBLIC_URL — سيبقى زر واتساب الدعم كقناة احتياطية وإشعار الأدمن كما هو.
